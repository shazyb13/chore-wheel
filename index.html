One-time sync setup

This lets everyone's copy of this file talk to each other over the internet, using a free account at jsonbin.io. Do this once, then share the same two values with your roommates so their copy connects to the same place.

  1. Create a free account at jsonbin.io.
  2. Go to API Keys in your dashboard and create an Access Key with Bins Create, Read and Update permission checked (leave Delete off).
  3. Go to the dashboard and click Create Bin. Paste in {"names":["Alex","Sam","Jordan","Riley"],"chores":["Kitchen & Dishes","Bathroom","Living Room & Trash","Floors & Common Areas"],"weekOffset":0,"anchorWeekStart":"2025-01-06T00:00:00.000Z","lastModified":1} and save it.
  4. Copy the Bin ID (shown on the bin's page/URL) and your Access Key into the two fields below.

Every roommate needs to enter the same Bin ID and Access Key in their own copy of this file (send it to them once, e.g. in your house group chat). The key lives only in this browser's storage — it isn't uploaded anywhere except to jsonbin.io itself.
