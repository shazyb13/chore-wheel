One-time sync setup

This connects everyone's copy of the app over the internet using a free account at jsonbin.io. Do this once, then share the same two values with your housemates.

  1. Create a free account at jsonbin.io.
  2. Under API Keys, create an Access Key with Bins Create, Read and Update ticked (leave Delete off).
  3. Under Bins, click Create a Bin, paste this in, and save: {"names":["Alex","Sam","Jordan","Riley"],"chores":["Kitchen & Dishes","Bathroom","Living Room & Trash","Floors & Common Areas"],"weekOffset":0,"anchorWeekStart":"2025-01-06T00:00:00.000Z","lastModified":1}
  4. Copy the Bin ID and your Access Key into the fields below.

Everyone enters the same Bin ID and Access Key. They're stored only in this browser.
